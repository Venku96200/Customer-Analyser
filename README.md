# Customer.Ai — Churn Prediction MVP

A minimal FastAPI backend that serves a trained customer churn prediction
model, with a simple web form for live single-customer predictions.

## Problem

Telecom/subscription companies lose revenue when customers churn without
warning. This tool takes one customer's account details and returns a churn
probability and risk level, so retention teams can act before it's too late.

## Tech stack

- **Backend:** FastAPI (Python)
- **ML:** scikit-learn model, trained on the Telco Customer Churn dataset
- **Serving:** pickle-serialized model + label encoders, loaded at
  startup for fast inference
- **Frontend:** plain HTML/CSS/JS calling the API directly (no framework)

## How it works

1. Model was trained in a Jupyter notebook (`notebooks/` — training code,
   not included in the served app) using scikit-learn, with categorical
   features label-encoded and numeric features scaled.
2. `main.py` loads the saved model and encoders once at startup.
3. `POST /predict` takes a customer's raw field values (e.g. `Contract:
   "Month-to-month"`), encodes/scales them exactly as done in training, and
   returns:
   - `churn_probability` — model's predicted probability of churn
   - `risk_level` — Low / Medium / High
   - `prediction` — Churn / No Churn

## Running locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Then open `http://localhost:8000/app` for the form, or `http://localhost:8000/docs`
for interactive API docs.

The app loads `churn_model/Customer_Churn_model.pkl` and
`churn_model/encoders.pkl`, generated by the training notebook. This
random-forest model does not require a scaler.
